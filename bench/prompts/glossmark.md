This repository describes its domain with GlossMark. Before you change code, read the vocabulary for the directory you are in (the session briefing, AGENTS.md, or the `glossmark` MCP server: `concepts_for_path`, `search_concepts`, `lookup_concept`). Link what you add with `@gloss` markers to existing concepts; if no concept fits, propose one with `ns:NEW:Name` and `propose_concept` rather than editing an ontology file by hand. Before you finish, run `gloss check` and `gloss diff --base HEAD` and resolve what they report: a HARD result means a person must decide, so leave the change as a proposal and say why in your final message.
